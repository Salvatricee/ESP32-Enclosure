# ESP32 Enclosure, Pointers and Memory Assignment

## Overview

This repository contains my work for the ESP32 Enclosure, Pointers and Memory assignment. The assignment combines 3D enclosure design using Onshape with practical concepts in C/C++ programming, pointers, and ESP32 memory management.

## Part 1: ESP32 Enclosure Design

The ESP32 enclosure was designed using **Onshape**. The design consists of a protective base and a removable lid intended to house an ESP32 development board.

### Main Design Features

* Enclosure base with protective walls
* Four internal standoffs for mounting the ESP32 board
* 2.7 mm screw holes in the standoffs for M3 self-tapping screws
* USB connector cutout on the enclosure wall
* Ventilation openings to allow heat to escape
* Rounded/chamfered external edges for improved safety and appearance
* Removable lid with appropriate clearance for assembly
* Dimensions and clearances designed according to the assignment requirements

### Design Considerations

The enclosure was designed to provide enough space for the ESP32 board while keeping the components protected. The standoffs provide mounting points for the board, while the USB cutout allows access to the USB connector without opening the enclosure. Ventilation holes were included to improve airflow and reduce heat buildup during operation.
